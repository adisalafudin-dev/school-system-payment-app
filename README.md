# SPP_app
Sumbangan Pembinaan Pendidikan (SPP) adalah biaya pendidikan bagi mahasiswa /siswa yang diperuntukkan untuk menunjang kebutuhan perguruan tinggi / sekolah dalam menyelenggarakan proses pendidikan. Nominal SPP tiap perguruan tinggi berbeda-beda, tergantung dari kebijakan kampus dan status perguruan tinggi.
